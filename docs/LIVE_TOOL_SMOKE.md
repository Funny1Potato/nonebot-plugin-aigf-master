## 最新：重复与故障场景验证

同一份修复后源码验证 7 类场景共 17 次全部通过：新增记忆、原位修改、普通回复各 3 次；写入失败、发送超时、主动沉默、轮次耗尽各 2 次。

| 检查 | 修复前重复样本 | 修复后重复样本 |
| --- | --- | --- |
| 基础三场景 | 8/9；一次 parts 对象代替数组，三轮未纠正 | 9/9 |
| 故障/沉默/预算四场景 | 7/8；一次写入失败后重复查询，未及时说明 | 8/8 |
| 参数校验失败调用数 | 4（含已纠正的调用） | 0 |

模型可见 schema 展开为内联结构，明确数组和 owner_id 适用范围；list_type 回执明确拒绝 item 包装和字符串数组。工具异常回执及提示约束最多一次只读确认，避免反复查询耗尽轮次。所有严格参数验证保留，没有自动修补或类型强转。

程序增加整批发送停止保护：任何一次发送结果未知后，新 key、新内容和后台图片都不能继续发送；已记录效果仍可查询回执，重建同一批 sender 也保留停止状态。新批次不受该批停止标记影响。该保护由离线故障注入验证，不能仅依赖模型自觉。

故障场景使用真实模型和生产工具，但磁盘写入错误、平台发送超时由测试注入。写入失败后没有提交或错误成功确认；发送超时只尝试一次，未写入虚假机器人发言；预算只有一轮时不额外请求确认。修复后 17 个场景累计服务商报告 129190 tokens，单场景耗时 1.97–7.70 秒，仅代表本次小样本，不推断费率或生产表现。

离线工具协议共 42 个 unittest；最终 3.10 默认 12/12、3.14 含矩阵 14/14 通过，相关套件在更新测试回执及同步运行副本后复测通过。另有一次未复现的离线发送未确认已保留在 [回归记录](../tests/BASELINE.md)，原因尚未确认，不用重复通过覆盖该记录。

完整脱敏记录含修复前后源码哈希：[重复验证快照](../tests/baselines/2026-11-13-tool-stability.json)。本次隔离检查通过，尚不能替代真实会话、平台、实服务与日常周期灰度验收；默认仍为 legacy_json。

## 初轮检查与历史记录

新增长期记忆、原位修改已有长期记忆、普通问候，三个场景分别通过。记忆提交回执先于确认消息；修改后只有一个新条目；普通问候没有写记忆。

这还不能视为稳定性验收。初始检查发现参数类型错误，提交记忆后未能发出确认；补充 schema 和提示后也观察到一次 parts 数组类型错误，模型连续修正失败并耗尽 3 轮预算。程序没有猜测或强制转换参数，也没有把未发送的消息记成已发言。之后三个单独场景通过，不能用后续成功覆盖前面的失败。

已修复的接口缺口：模型可见 schema 现在表达 text/at/meme 的互斥字段，以及 add/modify/delete 的必填与禁止字段；提示明确字符串记忆和文化对象的区别。INVALID_ARGUMENTS 回执附带有数量和长度限制的字段错误，不回显输入原文，允许模型根据具体错误修正。

验证记录保留全部尝试，包含一次开发中 schema 构造错误导致的本地中止，该次没有发出模型请求，不计作服务商失败。脱敏记录见 [真实模型检查快照](../tests/baselines/2026-11-13-live-tool-smoke.json)。样本很少且跨多个开发阶段，不用于估计成功率。

## 可复跑入口

使用机器人虚拟环境，在运行工作区执行：

```powershell
.\.venv\Scripts\python.exe ..\nonebot-plugin-aigf-master\tools\smoke_tool_model.py --workspace . --env-file .env.dev --live --case all
```

- 必须显式提供 `--live`，会产生现有模型服务的实际调用费用。
- `--case all` 覆盖 add/modify/chat；`--case extended` 覆盖 memory_failure/send_timeout/silence/budget；也可以单选上述任一场景，默认 add。
- `--repeat 1..10` 控制重复次数；默认失败即停止，`--keep-going` 保留并继续剩余样本。
- 只读取 `.env`、指定环境文件及进程环境中的模型和代理配置，不加载群列表、真实聊天或 peer 设置；不改配置文件。
- 每个进程新建 `tests/.results/live-tool-smoke-*`，NoneBot 使用无网络驱动和该目录下的 localstore；不运行启动钩子。
- 使用生产 processor、prompt、工具 schema、记忆存储和发送器，仅捕获最终平台发送。每个场景最多 3 轮、12 次工具调用、180 秒；budget 场景主动限制为 1 轮。
- 报告包含停止原因、效果状态、校验错误位置、参数类型结构、逐轮工具名称、源码哈希和服务商提供的 token 用量；不记录凭据、地址、模型输出正文或完整请求。
- 默认不属于 `tests/run_offline.py`，离线回归不会触发网络或模型费用。
