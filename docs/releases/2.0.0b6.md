# 2.0.0b6

本版本为 beta 预发布，在 b5 的可选多轮工具协议上增加按会话切换、运行诊断、peer 请求关联和自动发布质量门槛。默认仍为 `legacy_json`，不会因升级自动启用 tools。

## 新增与修复

- 按完整会话键设置 `AIGFM_SESSION_PROTOCOLS`；超级用户可在当前会话执行 `action_protocol tools`、`action_protocol legacy_json` 或 `action_protocol default`。管理员覆盖持久化保存，下一批生效，当前批保持原协议；不同会话独立。
- `status` 增加当前/下一批协议、近期停止原因、耗时、模型轮次、工具调用数、实际报告的 token、被忽略的结束文本及工具失败码。诊断保留最近 20 批摘要，展示最近 5 批，重启清空；摘要不保存正文或工具参数。
- 主端 peer 调用、回执、捕获输出通过 `request_id` 关联，按来源与会话核对，区分已接收、收到输出和等待超时。超时或取消不会自动重发；迟到输出可更新状态。收到输出仍不代表完整执行或聊天平台发送成功。
- 发布质量门槛覆盖 Python 3.10/3.14 离线回归、完整包源码核对、tag/版本一致性、wheel/sdist 独立干净安装、依赖检查与插件加载；通过后上传同一组已验证产物。
- 修复 CI 默认忽略隐藏测试结果目录的问题，测试诊断日志与构建产物均保留为 Actions 产物。

## 安装与使用

```console
pip install --upgrade nonebot-plugin-aigf-master==2.0.0b6
```

升级前备份插件数据。首次从旧版本启用工具模式会初始化记忆 entry_id/revision 并保留 `.pre-tools.bak`；从 b5 升级继续使用已有数据与条目引用。降级旧二进制前仍需检查非 OneBot 好友命名空间兼容性。

按会话灰度的初始配置示例：

```dotenv
AIGFM_ACTION_PROTOCOL=legacy_json
AIGFM_SESSION_PROTOCOLS={"onebot11:123456":"tools"}
```

管理员命令使用机器人配置的命令前缀，例如 `/action_protocol tools`；`default` 恢复该会话环境配置，再回落到全局配置。`reset` 不清除持久化的协议覆盖。

本体与 peer 独立部署、独立发布。完整的请求与回传关联需要 peer 侧也支持 `request_id`；旧 peer 仍能调用和推送，但无法可靠关联，不能因等待超时自动重试。本次仅发布本体，未同步发布 peer。

- 发布前的远端 Ubuntu 质量门槛通过：本体 Python 3.10 为 15/15，Python 3.14 含适配器矩阵为 17/17；wheel/sdist 独立安装、依赖检查与隔离加载通过。tag 发布仍须通过同一门槛。
- 实际 FastAPI 启动与外部模拟 OneBot 检查 25 项通过，涵盖协议切换、status、重启保留和恢复配置。
- 真实模型驱动的本机/peer 双实例路由检查 12 项通过，包含 request_id 往返；既有搜索和生图实服务验证范围见文档。
- 尚未连接真实聊天服务，未完成连续 24 小时灰度或压力验收；当前状态不代表生产稳定性验收。记忆协调锁仍限单进程，不能多进程共写同一数据目录。
