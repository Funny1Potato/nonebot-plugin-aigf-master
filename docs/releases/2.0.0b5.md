# 2.0.0b5

本版本为 beta 预发布，提供可选的多轮工具动作协议，并加固插件调用、跨适配器事件复制、存储和发送链路。

## 新增与修复

- 新增 tools 动作协议：消息发送、记忆查询/修改、表情收藏及命令学习通过显式工具执行；普通结束文本不发送，最终 reply/memory JSON 不执行。
- 默认每批最多 3 轮、12 次工具调用、3 次发送；支持参数校验、具体字段纠错、发送去重、记忆 entry_id/revision 冲突检查和效果记录恢复。
- 模型发言与后台生图共用 MessageSender，固定创建时的会话；按实际发送结果记录历史，未知结果停止本批新发送，不自动补发。
- 本机与 peer 命令共用批次额度，保留白名单、管理命令拒绝、去重和社交能量限制；投递/接收回执不再被当作执行完成证明。
- 修复 Satori 消息缓存、Kaiheila 只读消息槽位及通知会话回落；保留原生 @ 和结构化消息 id。
- 修复插件输出捕获钩子对资料查询 API 的会话解析重入风险；搜索服务失败与正常空结果明确区分。
- 回填 main 1.6.3/1.6.4 的文本 @、多模态默认和图片相关改进；补充离线测试、实际启动及实服务复跑入口。

## 启用与升级

默认仍为 legacy_json；新工具模式需显式设置：

```env
AIGFM_ACTION_PROTOCOL=tools
```

升级前备份插件数据。首次工具初始化保留 `.pre-tools.bak` 并添加条目元信息；非 OneBot 好友命名空间适配也涉及系统资料新写入。降级旧二进制前需核对新命名空间的读取/导出，不能仅靠切回旧协议恢复所有旧版读取方式。

本体与 peer 独立安装、独立发布。peer 侧的事件复制和捕获修复不会随本体安装包更新，需要另外升级对应 peer 版本。

## 验证与边界

- Python 3.10 默认 13/13、Python 3.14 含矩阵 15/15 套件通过；工具协议 44 个 unittest。
- 实际启动 aigf-manager，通过独立 OneBot 模拟平台的反向 WebSocket 验证鉴权、收发、原生 @、reset 与服务重启恢复。
- 实际本机插件、双实例 peer HTTP、搜索和后台生图共 16 项检查通过；真实记忆副本的离线迁移检查通过，原数据未改。
- 尚未连接真实聊天服务，未完成连续 24 小时灰度，不作生产稳定性承诺。所有替代后端、图生图及图像理解实服务组合未逐一覆盖。
